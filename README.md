ARVA – Sign-up Form

A sign-up form page built as part of The Odin Project curriculum.

ARVA is a fictional risk analysis service – this is not a real online service.

Built with
HTML
CSS (Flexbox, Grid)
Features
Split layout with a decorative side panel and logo
Two-column form layout using CSS Grid
Built-in browser validation (required, minlength, type="email")
Red border on invalid fields using :user-invalid
Custom focus style using :focus
What I learned
Using Flexbox and Grid together
How CSS rule order and specificity affect styles
Styling form inputs and validation states
Connecting a button outside a form with the form attribute
